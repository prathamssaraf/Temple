# Temple — Temporal Pattern Engine

A modular system for detecting repeatable stock market price behavior patterns.

## Components

| Component | Description |
|-----------|-------------|
| **data** | Fetch & cache OHLCV + fundamental data |
| **patterns** | Pluggable pattern detection strategies |
| **scanner** | Apply strategies across stock universe |
| **dashboard** | UI for exploration & configuration |
